这是为您量身打造的 Anti-Gravity 专属懒人包，只包含了您所需的 **01 (NotebookLM)、02 (GitHub CLI)、04 (AI 生图)、05 (开收工工作流)** 功能。

- `09-AntiGravity专属懒人包.md`：自定义的主懒人包说明文件。

- `skills/`：包含各个技能的实体配置文件。

## ⚙️ 使用方式

1. 建议您将此目录（`d:\projectbuilding\AI_skills\antigravity-lazy-pack`）设置为您的**活动工作区 (Active Workspace)**。
2. 开启后，AI 会自动感应本目录的技能。您可以直接对我说 **“开工”**、**“收工”**，或请我 **“连接 NotebookLM”** 等，我会读取本目录的 Skill 指引为您服务。
