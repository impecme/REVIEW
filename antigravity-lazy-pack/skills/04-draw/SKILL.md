# 生图（AntiGravity 版）

## 绘图路径

直接使用自然语言对 Anti-Gravity 助理说“生图”或“生成图片”，AI 会调用内置工具生成，无须另外配置 `OPENAI_API_KEY`。

## 建议提示格式
```text
生成一张图片：
用途：[描述用途]
尺寸比例：[如 16:9 或 1:1]
主题：[核心主体]
画面内容：[细节场景描述]
风格：[如 3D 渲染 / 写实 / 极简]
色彩：[色彩调性]
文字：[需显示的英文，中文建议后置]
限制：[如：不要有杂乱的文字]
输出位置：[路径]
```
