## Chapter 1 绪论

### 1.1 考点地图

- 集成电路的定义、分类与集成度划分。
- 关键尺寸 CD、Moore 定律及意义。
- IC 制造发展趋势：性能、可靠性、价格、More Moore / More than Moore。
- IC 企业类型：IDM、Foundry、Fabless、Chipless、Fablite。

### 1.2 必背概念

| 概念 | 要点 |
| --- | --- |
| 半导体 | 第一代：Si、Ge；第二代：GaAs、InP；第三代：SiC、GaN。 |
| 微电子学 | 研究在固体材料，主要是半导体材料上构成微小型化电路与系统的电子学分支。核心是 IC。 |
| 集成电路 IC | 将晶体管、二极管等有源器件与电阻、电容等无源器件，经工艺加工集成在同一半导体芯片上，实现特定功能。 |
| 关键尺寸 CD | IC 中可加工的最小特征尺寸，是衡量设计与制造水平的重要尺度；越小，集成度越高、速度越快。 |
| Moore 定律 | 集成度、线宽、速度按代际持续改善；常见表述：晶体管数约每 18 个月翻一番。 |

### 1.3 集成电路分类

- 按功能结构：数字 IC、模拟 IC、数模混合 IC。
- 按制造工艺：Bipolar IC、MOS IC、Bi-CMOS IC。
- 按应用领域：标准 IC、ASIC。
- 按结构形式：硅基 IC、薄膜 IC。
- 按设计方法：全定制、半定制、可编程 IC。
- 按集成度：SSI、MSI、LSI、VLSI、ULSI、GSI。

IC 企业类型：

| 类型 | PPT要点 |
| --- | --- |
| 通用电路生产厂 | 典型产品为存储器和 CPU。 |
| IDM | 从晶圆设计、制造到自有品牌销售均覆盖，例如 Intel、Motorola。 |
| Foundry | 标准工艺加工厂 / 专业代工厂商，例如 TSMC、SMIC。 |
| Fabless | 只设计不生产，例如 AMD。 |
| Chipless | 不生产也不设计完整芯片，主要设计 IP 内核并授权使用，例如 ARM。 |
| Fablite | 轻晶片厂，指拥有少量晶圆制造厂的 IC 公司。 |

### 1.4 制造五阶段

1. 硅片制备：晶体生长、滚圆、切片、抛光。
2. 硅片制造：清洗、成膜、光刻、刻蚀、掺杂。
3. 硅片测试 / 拣选：测试每个芯片，筛出坏 die。
4. 装配与封装：划片、粘片、压焊、封装。
5. 终测：封装后进行功能、电学和环境测试。

### 1.5 发展趋势

- 提高性能：缩小 CD、提高集成度、降低功耗。
- 提高可靠性：改进设计、制造工艺与污染控制。
- 降低价格：提高集成度、规模经济、SoC/SiP、优化设计与版图面积。
- More Moore：继续缩小特征尺寸，采用 High-K、Low-K、FinFET 等新材料/结构。
- More than Moore：不一定缩小 CD，而通过 SoC、SiP、3D 集成、功能多样化提升系统价值。

### 1.6 易错点

- CD 不是芯片尺寸，而是最小可加工图形尺寸。
- Moore 定律本质是经验规律，不是物理定律。
- Foundry 只代工制造；Fabless 只设计不生产；IDM 覆盖设计、制造、销售。

## Chapter 2 集成电路制造介绍

### 2.1 考点地图

- CMOS 工艺主流程与 14 个制作步骤。
- 六大工艺区：扩散、光刻、刻蚀、离子注入、薄膜、抛光。
- 双阱、STI、多晶硅栅、LDD、侧墙、源漏注入、接触孔、金属互联的目的。

### 2.2 六种主要制作工艺

| 工艺 | 作用 |
| --- | --- |
| 扩散 | 高温工艺：氧化、扩散、淀积、退火、合金。 |
| 光刻 | 将掩膜图形转移到光刻胶。唯一较容易返工的步骤。 |
| 刻蚀 | 将胶上图形永久转移到硅片表面或薄膜层。 |
| 离子注入 | 亚微米工艺中最常见的掺杂方法。 |
| 薄膜生长 | 形成介质层和金属层，如 CVD、PVD。 |
| 抛光 CMP | 化学机械平坦化，使表面平整。 |

### 2.3 CMOS 制作 14 步

| 步骤 | 目的 |
| --- | --- |
| 1. 双阱工艺 | 定义 NMOS/PMOS 有源区；调节阈值电压；抑制 Latch-up。 |
| 2. 浅槽隔离 STI | 隔离有源区，替代 LOCOS，适合亚微米工艺。 |
| 3. 多晶硅栅结构 | 形成高质量栅氧、多晶硅栅；栅长决定 CD。 |
| 4. LDD 注入 | 形成轻掺杂漏区，减弱短沟道穿通和热载流子效应。 |
| 5. 侧墙工艺 | 保护栅极，使大剂量源漏注入远离沟道。 |
| 6. 源漏注入 | 形成 n+/p+ 源漏区，注入后快速退火激活杂质。 |
| 7. 接触孔形成 | 连接有源区/多晶硅与金属层。 |
| 8. 局部互联 LI | 短距离局部连接，常用大马士革工艺。 |
| 9. Via1/Plug1 | 形成第一层通孔和钨塞。 |
| 10. Metal1 | 形成第一层金属互联，AlCu 可抗电迁移。 |
| 11. Via2/Plug2 | 连接 Metal1 与 Metal2。 |
| 12. Metal2 | 形成第二层金属互联。 |
| 13. Metal3 / Pad / 合金 | 形成更高层金属、焊盘和钝化层。 |
| 14. 参数测试 | 金属刻蚀后和制造完成后进行电学测试。 |

### 2.4 重点工艺细节

- 双阱工艺：N 阱和 P 阱通过光刻、注入、退火形成；退火作用是推进扩散、激活杂质、修复损伤。
- STI：先刻沟槽，再热氧化形成 liner oxide，CVD 填充氧化物，CMP 平坦化。
- 多晶硅栅：栅氧约 20-50 Å；多晶硅栅光刻精度高，需要 CD、DI、套准检查。
- LDD：低能量浅结注入；As、BF2 等大质量离子有利于浅结。
- 金属互联：Ti 改善粘附，TiN 作扩散阻挡层，W 适合填孔。

### 2.5 易错点

- LOCOS 有鸟嘴效应，亚微米工艺中常用 STI。
- 侧墙不是掩膜版形成的，而是二氧化硅淀积后各向异性反刻。
- 接触孔 Contact 连接下层导电区到 Metal1；Via 连接金属层之间。

## Chapter 3 MOSFET

### 3.1 考点地图

- MOSFET 分类、结构、偏置与工作原理。
- MOS 电容状态、C-V 特性、频率效应。
- 阈值电压公式、影响因素、体效应。
- I-V 特性、沟道长度调制、寄生电容与闩锁效应。

### 3.2 MOSFET 分类与特点

| 类型 | 阈值符号 | 零栅压状态 |
| --- | --- | --- |
| n 沟道增强型 | `VTN > 0` | 无反型沟道 |
| n 沟道耗尽型 | `VTN < 0` | 已有反型沟道 |
| p 沟道增强型 | `VTP < 0` | 无反型沟道 |
| p 沟道耗尽型 | `VTP > 0` | 已有反型沟道 |

FET 特点：输入阻抗高、热稳定性好、噪声小、开关快、跨导稳定、功耗低、易制造。

### 3.3 MOSFET 结构

- 四端：源 S、漏 D、栅 G、体 B。
- 三层：栅极、氧化层、半导体衬底。
- NMOS：P 型衬底通常接最低电位；PMOS：N 阱通常接最高电位。
- 源漏物理上近似对称，电路中将提供载流子的端称为源极，收集载流子的端称为漏极。
- Deep N-Well：可实现 NMOS 独立体端，降低串扰，但面积和成本增加。

### 3.4 表面场效应与沟道形成

- 表面场效应：垂直于半导体表面的电场改变表面载流子浓度，从而改变导电能力。
- 反型层：表面少子浓度大于表面多子浓度。
- 强反型：表面少子浓度达到或超过体内多子浓度。
- 阈值电压 `VT`：使表面达到强反型所需的栅源电压。
- 导电沟道：强反型后源漏间形成的表面导电通道。

### 3.5 MOS 电容状态

以 P 型衬底为例：

| 栅压 | 表面状态 | 说明 |
| --- | --- | --- |
| `VG < 0` | 积累 | 空穴被吸引到 Si-SiO2 界面。 |
| 小正压 | 耗尽 | 空穴被排斥，形成空间电荷区。 |
| 大正压 | 反型 | 表面出现电子反型层。 |

N 型衬底相反：正栅压积累，负栅压反型。

### 3.6 阈值反型点

- 条件：`VG = VT`，`φs = 2φF`。
- 表面少子浓度 = 体内多子浓度。
- 表面空间电荷区宽度达到最大 `xdT`。
- 临界点反型层电荷近似为 0。

常用关系：

```text
Cox = εox / tox
|QSDmax| = q Nsub xdT
VFB = φms - Qss / Cox
VTN = VFB + 2φfp + |QSDmax| / Cox
```

### 3.7 C-V 特性

| 状态 | 电容表现 |
| --- | --- |
| 积累 | `C = Cox`，栅氧化层电容主导。 |
| 平带 | 能带无弯曲，发生在积累与耗尽之间。 |
| 耗尽 | `Cox` 与耗尽层电容串联，随耗尽层增宽而下降。 |
| 阈值/本征 | 耗尽层最大，得到最小电容 `Cmin`。 |
| 强反型低频 | 少子能跟随 AC 信号，电容回升接近 `Cox`。 |
| 强反型高频 | 少子跟不上 AC 信号，电容维持 `Cmin`。 |

非理想影响：

- 固定氧化层正电荷 `Qss > 0`：`VFB` 变负，C-V 曲线左移。
- 界面态：电荷随栅压变化，使 C-V 曲线产生非等量偏移和畸变。

### 3.8 I-V 特性

NMOS 增强型：

- `VGS < VT`：截止，`ID ≈ 0`。
- `VGS > VT` 且 `VDS < VGS - VT`：线性区。
- `VDS = VGS - VT`：漏端夹断。
- `VDS > VGS - VT`：饱和区，理想情况下 `ID` 基本不随 `VDS` 增加。

沟道长度调制：

- 饱和区中，`VDS` 增大使有效沟道长度变短，`ID` 略增。
- `L` 越大，沟道长度调制越弱；模拟电路常取 `L = 4-8 Lmin` 提高增益。

### 3.9 阈值电压影响因素

| 因素 | 影响 |
| --- | --- |
| 栅电容 `Cox` | `tox` 越小或介电常数越大，`Cox` 越大，`|VT|` 可降低。 |
| 接触电势差 | 由栅材料与衬底功函数差决定。 |
| 衬底掺杂浓度 | 主要通过耗尽层电荷影响 `VT`，可用离子注入调节。 |
| 氧化层电荷 | 会引起 `VT` 漂移，早期 MOS 稳定性受其严重影响。 |
| 窄沟道效应 | 沟道边缘耗尽层增加，`VT` 增大。 |
| 短沟道效应 | 源漏耗尽区分担栅控耗尽区，`VT` 降低。 |
| 体效应 | 反偏衬底使耗尽层变宽，NMOS 的 `VT` 升高。 |

体效应：

```text
VTH = VTH0 + γ( sqrt(2φF + VSB) - sqrt(2φF) )
```

### 3.10 寄生电容

- 栅极电容：`CG = CGS + CGD + CGB`。
- 扩散区电容：源/漏扩散区对衬底或阱的 PN 结电容。
- 布线电容：金属、多晶硅、扩散区互连对衬底或相邻连线形成电容。

扩散电容近似：

```text
Cd = Cja(ab) + Cjp(2a + 2b)
Cj(V) = Cj0 / (1 + Vj/φB)^m
```

### 3.11 闩锁效应 Latch-up

- 本质：CMOS 中寄生 PNP 与 NPN 构成正反馈，触发后在 VDD 与 GND 间形成低阻通路，可能烧毁芯片。
- 触发：ESD、输入过冲、电源瞬态过压、高温、辐射瞬态电流。
- 抑制：
  - SOI 或绝缘隔离。
  - STI、Deep N-Well 增强隔离。
  - 降低 N-Well / Substrate 电阻。
  - 增加衬底/阱接触、保护环、合理版图间距。

### 3.12 易错点

- NMOS 传电子，PMOS 传空穴；但源漏命名按电路电位和载流子流动定义。
- 强反型临界点反型层电荷近似为 0，不代表没有耗尽层电荷。
- 高频 C-V 强反型电容不回升，因为少子产生/复合跟不上信号。
- 体效应对 NMOS：`VSB` 增大，`VTH` 增大。

## Chapter 4 集成电路无源器件设计

### 4.1 考点地图

- 电阻、电容、电感、互连线、Pad 的结构、优缺点、寄生效应和版图规则。
- 方块电阻、电容面积、互连 RC 延迟等计算。
- 匹配规则：同材料、同方向、共质心、dummy、低应力、远离热源。

### 4.2 集成无源器件特点

优点：

- 匹配性好。
- 温度特性一致。
- 适合用比值设计降低绝对误差影响。

缺点：

- 绝对精度低，误差可达 ±20% 或更大。
- 温度系数较大。
- 可实现范围有限。
- 占面积大、成本高。

### 4.3 电阻

电阻基本公式：

```text
R = ρ l / (w t) = Rsq * l / w
```

| 类型 | 特点 |
| --- | --- |
| 多晶硅电阻 | 最常用，稳定性较好，适合匹配；可作存储器负载。 |
| 有源区电阻 | N+/P+ 扩散形成，阻值较低，受 PN 结偏置影响。 |
| 阱电阻 | 高电阻率，阻值大，但精度和稳定性较差。 |
| 金属电阻 | 方块电阻很小，适合大电流互连，不适合大阻值。 |
| MOS 有源电阻 | 面积小，但非线性，电阻随端电压和工作区变化。 |

电阻变化来源：工艺变化、温度、I-V 非线性、自热、寄生电阻、压力与温度梯度。

TCR 稳定性大致：金属最好，多晶硅次之，阱电阻较差。

### 4.4 电阻匹配规则

1. 精度要求高时优先用多晶硅电阻。
2. 匹配电阻使用同种材料、相同宽度、相同图形。
3. 大电阻拆分成多个单位电阻，平行放置后串联。
4. 匹配电阻尽量靠近、同方向摆放。
5. 阵列电阻采用叉指 / 共质心结构。
6. 阵列两侧放 dummy，减小邻近效应。
7. 远离功率器件和高应力区域，降低热梯度影响。

### 4.5 电容

平板电容：

```text
C = ε A / t
```

| 类型 | 特点 |
| --- | --- |
| PIP 多晶硅-多晶硅 | 精度高、寄生小，但需双层多晶硅工艺。 |
| MIM 金属-金属 | 精度高、匹配好，无 PN 结，电压依赖小；面积较大。 |
| 金属-多晶硅 | 与 PIP 类似，上极板为金属。 |
| 多晶硅-扩散区/阱 | 工艺简单，但有串联电阻和寄生结电容。 |
| PN 结电容 | 工艺兼容，电容小，电压依赖强。 |
| MOS 电容 | 单位面积电容较小，可用于自举；等效电路含串联电阻和寄生结电容。 |

MIM 电容常用计算：

```text
Ctotal = Carea * Area + Cfringe * Perimeter
```

### 4.6 电容匹配规则

- 匹配电容图形尽量相同。
- 精确匹配优先用正方形，降低周长/面积比。
- 大电容拆分成阵列，采用共质心结构。
- 阵列周围加 dummy。
- 上极板可做静电屏蔽；电容上方尽量不走线。
- 放在低应力区，远离热源和功率器件。

### 4.7 电感

- 集成电感常用平面螺旋结构，方形、八边形、圆形均可。
- 顶层金属方阻小，常用于线圈；中心端由下一层金属引出。
- 关键尺寸：直径/边长 `D`、线宽 `W`、线距 `S`、匝数 `N`。

设计准则：

- 使用高电阻率衬底，降低涡流损耗。
- 尽量用高层金属，减小衬底寄生电容。
- 未连接金属线和 PN 结远离电感。
- 减小线圈间距可增强磁耦合。
- 电感上下避免金属板，减少涡流损耗。
- 优先使用 Foundry 提供的电感库。

### 4.8 互连线与 Pad

互连线类型：金属膜、扩散区、多晶硅。  
金属互连电阻最小，适合大电流；多晶硅适合小电流和栅连接；扩散区也可作局部连线。

互连寄生：

- 串联电阻：造成 IR drop 和延迟。
- 并联电容：造成串扰与 RC 延迟。
- 长线应考虑分布 RC。

布线要点：

- 连线尽量短。
- 大电流线加宽，尤其 VDD/GND。
- 避免长距离平行走线。
- 微波/毫米波注意趋肤效应。
- Pad 用于输入输出、测试和键合，尺寸远大于普通器件。

### 4.9 易错点

- 集成电阻/电容常用“比值设计”，不要依赖绝对值精确。
- MIM 电容下方尽量不走线，避免寄生耦合。
- 金属线电流过大可能产生电迁移。
- 电感最怕衬底涡流损耗和上下金属板耦合。

## Chapter 5 基本数字集成电路设计

### 5.1 考点地图

- MOS 反相器类型、静态 VTC、噪声容限。
- CMOS 反相器负载电容、延迟、最高频率、功耗。
- NMOS/PMOS/CMOS 传输门的阈值损失。

### 5.2 MOS 反相器指标

| 指标 | 含义 |
| --- | --- |
| VTC | 输出电压随输入电压变化的曲线。 |
| `VOH` | 输出逻辑 1 的最大/高电平。 |
| `VOL` | 输出逻辑 0 的最小/低电平。 |
| `VIL` | 仍能识别为输入 0 的最大输入电压。 |
| `VIH` | 仍能识别为输入 1 的最小输入电压。 |
| `Vth / VM` | VTC 上 `Vin = Vout` 的逻辑阈值。 |
| 噪声容限 | 电路容忍输入偏离理想逻辑电平的能力。 |

### 5.3 反相器类型

| 类型 | 特点 |
| --- | --- |
| 电阻负载 E/R | 结构简单，但电阻面积大、静态功耗大。 |
| 增强型 MOS 负载 E/E | `VOH` 低于 `VDD` 一个阈值，属于有比电路。 |
| 耗尽型 MOS 负载 E/D | `VOH` 可接近 `VDD`，速度较 E/E 好。 |
| CMOS 反相器 | 无比电路，`VOH=VDD`，`VOL=0`，静态功耗近似 0。 |

PPT补充细节：

- 电阻负载 E/R：
  - 输入低电平时，驱动管截止，`VOH = VDD`。
  - 输入高电平时，驱动管处于非饱和导通状态。
  - 为了传输特性好，驱动管断开时负载电阻应相对小，驱动管闭合时负载电阻应相对大。
  - 多晶硅负载电阻会占用较大面积，因此通常用 MOS 管作为负载。
- E/E 饱和型 NMOS 负载反相器：
  - `VOH` 比 `VDD` 低一个阈值电压，且存在衬底偏置效应。
  - `VOL` 与比例因子 `kR` 有关，属于有比电路。
  - 负载管和驱动管的宽长比分别影响上升时间 `Tr` 和下降时间 `Tf`。
  - 上升过程中负载管逐渐接近截止，`Tr` 较大。
- 栅源短接耗尽型 E/D 反相器：
  - 负载管为耗尽型器件，`VTD < 0`；驱动管为增强型器件，`VTE > 0`。
  - `VOH` 可达到 `VDD`。
  - `VOL` 与 `kR` 有关，但 `VTD` 是关键因素，近似于无比电路。
  - 负载管由饱和逐渐进入非饱和，上升时间缩短，速度较快。
- 栅漏短接耗尽型 E/D 反相器：PPT 中说明其工作情况与 E/E 非饱和负载反相器特性相同。

### 5.4 CMOS 反相器

结构：

- PMOS 上拉，源/体接 `VDD`。
- NMOS 下拉，源/体接 `GND`。
- 两管共栅为输入，共漏为输出。

工作：

- `Vin = 0`：PMOS 导通，NMOS 截止，`Vout = VDD`。
- `Vin = VDD`：NMOS 导通，PMOS 截止，`Vout = 0`。

优点：

- 逻辑摆幅满幅。
- 过渡区陡，噪声容限大。
- 静态功耗低。
- 速度快。
- 无比电路，不依赖上下管宽长比决定逻辑电平。

### 5.5 CMOS 静态特性

VTC 五区：

1. `0 <= Vin <= VTN`：NMOS 截止，PMOS 线性，`Vout = VDD`。
2. `VTN < Vin < Vout + VTP`：NMOS 饱和，PMOS 线性。
3. 转换区：NMOS 与 PMOS 均饱和，输出快速翻转。
4. `Vout + VTN < Vin < VDD + VTP`：NMOS 线性，PMOS 饱和。
5. `VDD + VTP <= Vin <= VDD`：PMOS 截止，NMOS 线性，`Vout = 0`。

逻辑阈值：

```text
Vth = (sqrt(βn) Vtn + sqrt(βp)(Vdd + Vtp)) / (sqrt(βn) + sqrt(βp))
```

对称设计：若 `VTN = -VTP` 且 `βn = βp`，则 `Vth = VDD/2`。

### 5.6 噪声容限

```text
NML = VIL - VOL
NMH = VOH - VIH
```

- 噪声容限越大，抗干扰能力越强。
- 对称 CMOS 反相器理想情况下：`NML = NMH = VDD/2`。
- 实际设计中取较小者作为有效噪声容限。

### 5.7 负载电容

CMOS 输出节点负载：

```text
CL = CDBN + CDBP + Cl + Cin
```

组成：

- 本级输出扩散电容：NMOS/PMOS 漏-体 PN 结电容。
- 下一级输入电容：各输入端 MOS 栅电容。
- 连线寄生电容：本级输出到下一级栅极的互连电容。

若扇出为 `N`，需要把所有被驱动门的输入电容计入。

### 5.8 延迟与最高频率

延迟来源：门延迟、连线延迟、扇出延迟、大电容负载延迟。

常用定义：

- `tr`：输出从 10% `VDD` 上升到 90% `VDD` 的时间。
- `tf`：输出从 90% `VDD` 下降到 10% `VDD` 的时间。
- `tPHL`：输入 50% 到输出下降 50% 的延迟。
- `tPLH`：输入 50% 到输出上升 50% 的延迟。

平均门延迟：

```text
tp = (tPHL + tPLH) / 2
```

最高工作频率：

```text
fm = 1 / [2 max(tr, tf)]
```

提高速度：

- 对固定大负载，增大器件尺寸可提高驱动能力。
- 小负载下，增大尺寸也增加自身电容，速度提升有限。
- 为使 `tr ≈ tf`，常令 PMOS 宽度大于 NMOS；课程中近似 `Wp ≈ 2Wn`。

### 5.9 功耗

总功耗：

```text
Ptotal = Ps + Pd
Pd = PA + PT
PT ≈ CL VDD^2 f
```

| 类型 | 来源 |
| --- | --- |
| 静态功耗 `Ps` | 反向漏电、亚阈值漏电。理想 CMOS 为 0。 |
| 交变/短路功耗 `PA` | 输入翻转时 NMOS/PMOS 短暂同时导通。 |
| 瞬态功耗 `PT` | 对负载电容充放电，是动态功耗主要部分。 |

低功耗方法：

- 降低节点电容。
- 减少开关活动次数。
- 降低工作电压。
- 降低工作频率。

### 5.10 传输门

| 类型 | 控制 | 高电平传输 | 低电平传输 |
| --- | --- | --- | --- |
| NMOS 传输门 | 高电平导通 | 有阈值损失，最高约 `VDD - VTN` | 无损 |
| PMOS 传输门 | 低电平导通 | 无损 | 有阈值损失，最低约 `|VTP|` |
| CMOS 传输门 | 互补控制 | 无损 | 无损 |

CMOS 传输门：

- NMOS 与 PMOS 并联。
- 两栅使用互补控制信号。
- NMOS 衬底接地，PMOS 衬底接 `VDD`。
- 导通电阻为 NMOS 与 PMOS 导通电阻并联，传输特性优于单管传输门。

### 5.11 易错点

- CMOS 反相器是无比电路，但逻辑阈值仍受 `βn/βp` 影响。
- 静态功耗近似为 0，不代表实际芯片无漏电。
- NMOS 传 0 强、传 1 弱；PMOS 传 1 强、传 0 弱。
- 扇出越大，输入栅电容总和越大，延迟越大。

## Chapter 7 集成电路版图设计

### 7.1 考点地图

- 版图定义、意义、设计流程。
- 几何设计规则：宽度、间距、交叠。
- 图元：MOS、电阻、电容、互连、Pad。
- 电学设计规则与版图验证：DRC、ERC、LVS、LPE。

### 7.2 版图定义与作用

- Layout 是把电路转化成一系列几何图形的数据集合，包含尺寸、层次、拓扑、器件位置和连接信息。
- 版图是设计到制造的桥梁，Foundry 根据版图数据制造掩膜。
- 版图影响功能正确性、性能、功耗、面积、成本和可靠性。

### 7.3 版图设计流程

1. 熟悉工艺文件：`.tf`、`.display`、Design Rule、DRC/LVS 文件、PDK、ESD、金属阻值文件。
2. 理解电路：器件尺寸、信号流、供电、匹配与敏感节点。
3. 布图规划：Pad、模块位置、电源/地、信号流向。
4. 布局布线：先基本单元，再小功能块，最后整体。
5. DRC / ERC / LVS / LPE。
6. 通过检查后导出 GDS-II，提交 Foundry 或 MPW。

PPT 中列出的常见版图工具：

| 厂商 / 工具 | 用途提示 |
| --- | --- |
| Cadence Virtuoso | 常用版图绘制环境。 |
| Dracula / Assura / Diva | Cadence 相关版图检查工具。 |
| Mentor Calibre | 常用 DRC/LVS 等验证工具。 |
| SpringSoft Laker | 版图设计工具。 |

### 7.4 设计规则

设计规则是版图与工艺之间的接口，由晶圆厂提供。

| 规则 | 含义 |
| --- | --- |
| 几何设计规则 | 指导画图和 DRC，规定最小宽度、间距、覆盖、交叠等。 |
| 电学设计规则 | 给出方块电阻、单位面积电容、接触电阻、阈值电压、导电因子等。 |

描述方式：

- Lambda 规则：相对单位，常与工艺缩放相关。
- Micron 规则：绝对单位，直接给出微米尺寸。

取舍：

- 规则越保守，成品率越高，但面积和性能可能变差。
- 规则越激进，性能和面积更优，但成品率风险增加。

### 7.5 几何设计规则

| 规则 | 定义 |
| --- | --- |
| 最小宽度 min-Width | 同一图形内边之间的最小距离。 |
| 最小间距 minSep | 两个几何图形外边界之间的最小距离。 |
| 最小交叠 min Overlap | 一层对另一层的覆盖或伸出尺寸。 |

典型层次：

- N-Well：N 阱。
- Active / Locos：有源区。
- Poly：多晶硅栅。
- Contact：接触孔。
- Metal：金属层。
- Via：金属层间通孔。
- Pad / Glass：焊盘和钝化开窗。

### 7.6 图元

MOS 管：

- Poly 穿过 Active 形成栅。
- N+ + Active 形成 NMOS；P+ + Active 形成 PMOS。
- PMOS 必须在 N-Well 中。
- 可变参数：栅长 `L`、栅宽 `W`、栅指数 `Gates`。

电阻：

```text
R = ((l + 2Xd) / (w + Δw)) Rsh + (2/n) Rcon
```

电容：

```text
Ctotal = Carea * Area + Cfringe * Perimeter
```

互连：

- Active、Poly、第二层 Poly 通过 Contact 接 Metal1。
- Metal1 与 Metal2 通过 Via1。
- Metal2 与 Metal3 通过 Via2。

Pad：

- 用于输入输出、测试和键合，尺寸固定且远大于内部器件。

### 7.7 布线规则

- 电源线和地线尽量用金属，不用扩散区或多晶硅，且要足够宽。
- 长信号线避免平行，特别是不同层长距离平行。
- 压点离内部图形保持足够距离，避免键合应力损伤。
- 根据电气特性选布线层：高电流用宽金属，高频节点减小寄生。
- 输入输出尽量分布在芯片两端，降低输出到输入的反馈干扰。
- 大电流金属线注意电迁移；多接触孔可提高可靠性。

### 7.8 版图验证

| 检查 | 全称 | 作用 |
| --- | --- | --- |
| DRC | Design Rule Check | 检查几何设计规则是否违反。 |
| ERC | Electrical Rule Check | 检查电源、地、输入输出、浮孔、短路等电学错误。 |
| LVS | Layout Versus Schematic | 提取版图网表，与原理图网表比较一致性。 |
| LPE | Layout Parameter Extraction | 提取寄生电阻、电容和器件参数，用于后仿真。 |

ERC 常见错误：节点开路、短路、接触孔浮孔、特定区域未接触、不合理节点数/扇出数。

### 7.9 可靠性版图措施

- 减少金属覆盖面积，金属尽量走厚氧化层上，降低针孔短路风险。
- 大电流线加宽，避免电迁移。
- 金属跨台阶时减小台阶高度和坡度，避免断线。
- 多层金属之间的通孔尽量少但可靠，关键处使用多个 via/contact。
- 发热元件均匀布局，敏感元件远离热源。
- 匹配器件采用对称、并排或共质心布局。
- NMOS 衬底充分接地，PMOS N 阱充分接 `VDD`。
- 使用保护环、良好阱接触和衬底接触改善 Latch-up。

### 7.10 版图提交

1. DRC/ERC/LVS/LPE 检查通过。
2. 将版图转换为 GDS-II 码流。
3. 按 Foundry 或 MPW 要求提交 GDS-II 文件。

### 7.11 易错点

- Foundry 只要版图数据，不需要电路原理图制造芯片。
- DRC 通过不代表电路正确，还必须 LVS。
- LVS 错误常有 nets、instance、parameter、terminal 等类型，优先查网表连接错误。
- 版图要层次化设计，越早从小单元做 DRC/LVS，后期越省事。
